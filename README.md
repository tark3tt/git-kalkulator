#C++ Kalkulator

Preprost kalkulator, napisan v programskem jeziku C++, ki omogoča osnovne aritmetične operacije.

#Funkcionalnosti

Seštevanje (+)

Odštevanje (-)

Množenje (*)

Deljenje (/)

Ostanek pri celoštevilskem deljenju (%)

Preverjanje veljavnosti številskega vnosa

Zaščita pred deljenjem z nič

Zahteve

Nameščen prevajalnik C++, na primer GCC

Terminal ali ukazna vrstica

#Prevajanje

g++ main.cpp -o kalkulator

#Zagon

V Windows terminalu zaženemo:

kalkulator.exe
